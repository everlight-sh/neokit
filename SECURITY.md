# Reporting a security issue

Please use GitHub's private vulnerability reporting for the public NeoKit repository when it is enabled. Include the affected version, a minimal reproduction, and the impact. Keep credentials, private data, and unredacted production logs out of the report. If private reporting is unavailable, ask the maintainers for a private channel before sharing the details.

The alpha support scope is documented in [the release guide](docs/alpha-release.md).
